# English

`wav.cpp` implements RIFF/WAVE PCM16 I/O. Public API and policies are documented
in [docs/WAV.md](../../docs/WAV.md). This library has no socket or recovery dependency.

---

# Русский

`wav.cpp` реализует чтение и запись RIFF/WAVE PCM16. Публичный API и правила
работы описаны в [docs/WAV.md](../../docs/WAV.md). Библиотека не зависит от сокетов
или модуля восстановления.
